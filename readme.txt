# پروژه Modeling

این پروژه شامل دو بخش **فرانت‌اند** و **بک‌اند** است که به‌طور کامل برای مدیریت آگهی‌ها و درخواست‌ها توسعه داده شده است. در این فایل README، تمامی اطلاعات مربوط به تکنولوژی‌ها، وابستگی‌ها، و نحوه استفاده از پروژه آورده شده است.

---

## 📦 **تکنولوژی‌های استفاده‌شده**

### **فرانت‌اند:**

- **Next.js**: فریمورک React برای ساخت اپلیکیشن‌های وب.
- **React**: کتابخانه جاوااسکریپت برای ساخت رابط کاربری.
- **Tailwind CSS**: فریمورک استایل‌دهی برای طراحی سریع و ریسپانسیو.
- **Zod**: برای اعتبارسنجی داده‌ها.

### **بک‌اند:**

- **NestJS**: فریمورک Node.js برای ساخت API‌های مقیاس‌پذیر.
- **Express**: فریمورک جاوااسکریپت برای مدیریت درخواست‌ها.
- **Mongoose**: ORM برای ارتباط با پایگاه داده MongoDB.
- **JWT**: برای احراز هویت کاربران.
- **Socket.io**: برای ارتباطات Real-Time.
- **Swagger**: برای مستندات API.

## ⚙️ **نصب پروژه**

### **نصب فرانت‌اند**

1. به پوشه **`modeling-frontend`** بروید:
    ```bash
    cd modeling-frontend
    ```

2. وابستگی‌ها را نصب کنید:
    ```bash
    npm install
    ```

3. برای راه‌اندازی پروژه در محیط توسعه:
    ```bash
    npm run dev
    ```

4. برای تولید فایل‌های Build:
    ```bash
    npm run build
    ```

### **نصب بک‌اند**

1. به پوشه **`modeling-backend`** بروید:
    ```bash
    cd modeling-backend
    ```

2. وابستگی‌ها را نصب کنید:
    ```bash
    npm install
    ```

3. برای راه‌اندازی پروژه در محیط توسعه:
    ```bash
    npm run dev
    ```

4. برای شروع سرور:
    ```bash
    npm run start
    ```

## 🔑 **پیکربندی‌ها**

- **فرانت‌اند**:
  - برای انجام درخواست‌های HTTP، از **`axios`** استفاده می‌شود.
  - برای مدیریت روت‌ها و صفحات از **`Next.js`** استفاده شده است.
  - **`cookie-parser`** برای مدیریت کوکی‌ها در فرانت‌اند استفاده می‌شود.

- **بک‌اند**:
  - **`NestJS`** برای ایجاد API‌های RESTful استفاده شده است.
  - **`mongoose`** برای ارتباط با MongoDB و ذخیره‌سازی داده‌ها استفاده می‌شود.
  - **`JWT`** برای احراز هویت و مدیریت نشست‌های کاربری.

---

## 🔧 **مدیریت خطاها و لاگ‌ها**

تمامی خطاهای سیستم در لاگ‌ها ذخیره می‌شوند. برای مشاهده لاگ‌ها در پروژه، می‌توانید از فایل `project-diagnose-log.txt` استفاده کنید که در مسیر ریشه پروژه قرار دارد. این فایل شامل اطلاعاتی مانند:

- **وابستگی‌ها و پکیج‌ها**
- **مسیرهای API**
- **توکن‌ها و نحوه استفاده از آن‌ها**
- **آدرس‌ها و پیکربندی‌ها**

---

## 📈 **چگونگی انجام تست‌ها**

برای انجام تست‌های مربوط به پروژه و بررسی عملکرد APIها، از **اسکریپت تست** استفاده کنید که مراحل مختلفی مانند ثبت‌نام، ورود، دریافت توکن و ارسال درخواست‌ها را انجام می‌دهد. اسکریپت تست به طور خودکار این مراحل را اجرا کرده و لاگ‌ها را ثبت می‌کند.

1. **اجرای تست**:
    ```bash
    node apiTest.js
    ```

این اسکریپت تمامی مراحل را بررسی کرده و خروجی آن در فایل `project-diagnose-log.txt` ذخیره می‌شود.
